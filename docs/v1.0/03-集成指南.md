# 03 · 集成指南

把 AndroidCMS 整套接入到一个新的 Android 工程，直到可编译运行。

---

## 0. 前置要求

| 项 | 版本 |
| --- | --- |
| minSdk | 31（Android 12） |
| compileSdk | 36 |
| AGP | 8.13.2 |
| Kotlin | 2.0.0 |
| Compose BOM | 2024.09.00 |
| NDK / CMake | CMake 3.22.1 |

---

## 1. 复制库模块

把 `modules/` 下三个目录拷到宿主**工程根目录**（与 `app` 同级）：

```
<宿主工程>/
├── app/
├── liquidglass/
├── continuous-rounded-corner/
└── shared-elements/
```

在 `settings.gradle.kts` 末尾追加（见 `gradle/settings-snippet.gradle.kts`）：

```kotlin
include(":liquidglass")
include(":continuous-rounded-corner")
include(":shared-elements")
```

---

## 2. 版本目录（version catalog）

三个模块的 `build.gradle.kts` 使用别名（`libs.plugins.kotlin.android`、
`libs.androidx.compose.bom` 等）。宿主需具备 `gradle/libs.versions.toml`：

- 若宿主没有：直接把本包 `gradle/libs.versions.toml` 复制过去；
- 若宿主已有：确保包含以下条目（值可按宿主调整，但别名必须存在）。

```toml
[versions]
agp = "8.13.2"
kotlin = "2.0.0"
composeBom = "2024.09.00"

[libraries]
androidx-compose-bom = { group = "androidx.compose", name = "compose-bom", version.ref = "composeBom" }
androidx-compose-ui = { group = "androidx.compose.ui", name = "ui" }
androidx-compose-ui-graphics = { group = "androidx.compose.ui", name = "ui-graphics" }
androidx-compose-foundation = { group = "androidx.compose.foundation", name = "foundation" }
androidx-compose-material3 = { group = "androidx.compose.material3", name = "material3" }

[plugins]
android-application = { id = "com.android.application", version.ref = "agp" }
kotlin-android = { id = "org.jetbrains.kotlin.android", version.ref = "kotlin" }
kotlin-compose = { id = "org.jetbrains.kotlin.plugin.compose", version.ref = "kotlin" }
```

> 注意：`haze`（`haze` / `haze-blur`，`2.0.0-alpha03`）已包含在本包 `libs.versions.toml` 中。

---

## 3. 复制组件源码与主题

把 `cms/*.kt` 放到宿主模块包 `ldyc/qy/music/` 下；
把 `theme/*.kt` 放到 `ldyc/qy/music/ui/theme/` 下。

```
app/src/main/java/ldyc/qy/music/
├── GlassTopBar.kt
├── CMBottomBar.kt
├── CMProgressBar.kt
├── CMSSwitch.kt
├── CMScrollView.kt
├── CMSelectMenu.kt
├── CMSwiper.kt
├── CMDebugOverlay.kt
├── CLEARMotion.kt
├── TabletLayout.kt
├── DeveloperSettings.kt
└── ui/theme/
    ├── Color.kt
    ├── Theme.kt
    └── Type.kt
```

> `cms/optional/CMPlayerBackground.kt` 依赖应用侧 `PlayerViewModel` / `PerformanceGovernor`，
> **不要**直接拷入，否则编译失败；需要时自行适配（详见组件手册第 9 节）。

> 若宿主包名不是 `com.lindicra.cms`，请全局替换源码中的 `package com.lindicra.cms`
> 与所有 `import com.lindicra.cms.*`。

---

## 4. 复制资源

```
res/font/*.ttf          →  app/src/main/res/font/      （主题排版依赖 R.font.harmonyos_sc_*）
res/drawable/chevron_left.xml  →  app/src/main/res/drawable/   （顶栏返回按钮图标）
```

`theme/Type.kt` 依赖 `R.font.harmonyos_sc_*`（Thin / Light / Regular / Medium / SemiBold / Bold / Black）；
`GlassTopBar.kt` 依赖 `R.drawable.chevron_left`。缺少任一资源都会导致编译失败。

---

## 5. 复制原生引擎（CLEAR Motion）

```
native/jniLibs/                     →  app/src/main/jniLibs/
native/clearmotion_jni_bridge.cpp   →  app/src/main/cpp/
native/CLEARMotionPro.h             →  app/src/main/cpp/
native/CpuFeatures.h                →  app/src/main/cpp/
native/CMakeLists.txt               →  app/src/main/cpp/
```

`app/build.gradle.kts`：

```kotlin
android {
    defaultConfig {
        ndk { abiFilters += listOf("arm64-v8a") }   // 按需增减
    }
    externalNativeBuild {
        cmake {
            path = file("src/main/cpp/CMakeLists.txt")
            version = "3.22.1"
        }
    }
}
```

## 6. 补齐依赖

`app/build.gradle.kts`：

```kotlin
dependencies {
    implementation(platform("androidx.compose:compose-bom:2024.09.00"))
    implementation("androidx.compose.ui:ui")
    implementation("androidx.compose.ui:ui-graphics")
    implementation("androidx.compose.foundation:foundation")
    implementation("androidx.compose.material3:material3")
    implementation("androidx.compose.material:material")
    implementation("androidx.compose.material:material-icons-extended")
    implementation("androidx.compose.animation:animation")

    // CMSelectMenu 毛玻璃
    implementation("dev.chrisbanes.haze:haze:2.0.0-alpha03")
    implementation("dev.chrisbanes.haze:haze-blur:2.0.0-alpha03")

    // CMSPlayerBackground 封面加载
    implementation("io.coil-kt:coil-compose:2.7.0")

    // 本地库模块
    implementation(project(":liquidglass"))
    implementation(project(":continuous-rounded-corner"))
    implementation(project(":shared-elements"))
}
```

不需要的组件可连同依赖一起省略：
- 不用 `CMSelectMenu` → 可不加 `haze`；
- 不用 `CMSPlayerBackground` → 可不加 `coil`、也不拷该文件。

## 7. 最小使用示例

```kotlin
// 主题包裹（Type.kt 提供 HarmonySansSCTypography）
CLEARmusicTheme {
    CMScrollBox(modifier = Modifier.fillMaxSize()) {
        CMSSwitch(checked = on, onCheckedChange = { on = it })
        CMSProgressBar(progress = 0.4f, dotStyle = CMSProgressDot.Hollow)
    }
}

// 调试覆盖层
override fun onCreate(...) {
    DeveloperSettings.init(this)
    DeveloperSettings.updateDebugOverlayEnabled(true)
}
```

## 8. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| `R.font.harmonyos_sc_*` 找不到 | 第 4 节字体资源没拷 |
| `R.drawable.chevron_left` 找不到 | 第 4 节 `res/drawable/` 没拷 |
| `Unresolved reference: screenScaleFactor / TABLET_MIN_DP` | `TabletLayout.kt` 没拷 |
| `Unresolved reference: CMSGlassBackButton / CMSecondaryGlassTopBar` | `GlassTopBar.kt` 没拷 |
| `Cannot resolve libs.plugins.kotlin.android` | 宿主缺 version catalog 别名（第 2 节） |
| `Unresolved reference: Accent` 等主题 token | `theme/*.kt` 未拷或包名不一致 |
| 运行闪退 `UnsatisfiedLinkError: clearmotion_jni` | 第 5 节 CMake 未配置或 `jniLibs` 未拷 |
| 弹簧/轮播无动效 | `libCLEARMotionPro.so` 未随 ABI 拷入 |
| 菜单无毛玻璃 | 未加 `haze` 依赖 |
| `CMSPlayerBackground` 报 `PlayerViewModel` / `PerformanceGovernor` 未解析 | 该组件在 `cms/optional/`，属业务组件，需替换为本地状态后再引入 |

---

## 9. 可选：独立成 library 模块

若希望以 `implementation(project(":cms"))` 方式引用，可把 `cms/` + `theme/` + `res/font/`
放进一个 `com.android.library` 模块，示例 `build.gradle.kts`：

```kotlin
plugins {
    id("com.android.library")
    alias(libs.plugins.kotlin.android)
    alias(libs.plugins.kotlin.compose)
}

android {
    namespace = "com.lindicra.cms"        // 保持与源码包一致，避免改 import
    compileSdk = 36
    defaultConfig { minSdk = 31 }
    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_11
        targetCompatibility = JavaVersion.VERSION_11
    }
    buildFeatures { compose = true }
}

dependencies {
    implementation(platform(libs.androidx.compose.bom))
    /* 其余依赖见第 6 节 */
    implementation(project(":liquidglass"))
    implementation(project(":continuous-rounded-corner"))
    implementation(project(":shared-elements"))
}
```

若该模块也要编译 JNI，把 `externalNativeBuild` 与 `jniLibs` 一并放进本模块即可。
