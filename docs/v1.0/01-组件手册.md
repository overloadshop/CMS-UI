# 01 · 组件手册

CMS 组件全部位于 `cms/`，包名 `com.lindicra.cms`。
除特别说明外，均直接读取 `com.lindicra.cms.ui.theme.*` 的主题 token（深浅色自适应）。

---

## 1. GlassTopBar — 玻璃顶栏 / 返回按钮

`cms/GlassTopBar.kt`
提供「页面容器 → 顶栏 → 返回按钮」一整族，均为 `CMS*` 命名。

### 1.1 `CMSGlassPage` — 毛玻璃页面容器

```kotlin
@Composable
fun CMSGlassPage(
    topInset: Dp,
    modifier: Modifier = Modifier,
    glassEnabled: Boolean = true,
    topBarReserve: Dp = CM_MAIN_TOP_BAR_RESERVE,
    bottomReserve: Dp = 0.dp,
    hazeState: HazeState? = null,
    maxContentWidth: Dp = Dp.Unspecified,
    topBar: @Composable BoxScope.(hazeState: HazeState) -> Unit,
    content: @Composable ColumnScope.() -> Unit
)
```

统一处理 `hazeSource` + 滚动内容 + 顶栏叠层 + 底部避让；内容从屏幕顶部开始，为顶栏毛玻璃提供真实模糊素材。

### 1.2 `CMSMainGlassTopBar` — 主页顶栏

```kotlin
@Composable
fun CMSMainGlassTopBar(
    title: String,
    topInset: Dp,
    hazeState: HazeState,
    modifier: Modifier = Modifier,
    glassEnabled: Boolean = true,
    style: CMSGlassTopBarStyle? = null,
    trailingContent: @Composable RowScope.() -> Unit = {}
)
```

大标题 + 右侧自定义内容（`trailingContent`），无底部边框。

### 1.3 `CMSecondaryGlassTopBar` — 二级页顶栏（含返回）

```kotlin
@Composable
fun CMSecondaryGlassTopBar(
    title: String,
    topInset: Dp,
    hazeState: HazeState,
    modifier: Modifier = Modifier,
    glassEnabled: Boolean = true,
    style: CMSGlassTopBarStyle? = null,
    onBack: (() -> Unit)? = null,          // 不传时自动 (context as ComponentActivity).finish()
    onTitleClick: (() -> Unit)? = null,
    trailingContent: @Composable BoxScope.() -> Unit = {}
)
```

左侧自动放置 `CMSGlassBackButton`，标题居中，带底部 1px 边框。

### 1.4 `CMSGlassBackButton` — 玻璃返回按钮

```kotlin
@Composable
fun CMSGlassBackButton(
    onClick: () -> Unit,
    iconColor: Color
)
```

40×40，SDK ≥ 33 走液态玻璃（`LiquidGlassView`），否则回退半透明底。
箭头图标使用 `R.drawable.chevron_left`。

### 1.5 `CMSGlassTopBarStyle` — 顶栏样式

```kotlin
data class CMSGlassTopBarStyle(
    val background: Color,
    val materialOverlay: Color,
    val overlayTint: Color,
    val blurRadius: Dp = 22.dp,
    val highlightColor: Color = Color.Transparent,
    val borderColor: Color = Color.Transparent
) {
    companion object {
        val dark: CMSGlassTopBarStyle    // 暗色默认
        val light: CMSGlassTopBarStyle   // 亮色默认
        val clear: CMSGlassTopBarStyle   // 完全透明毛玻璃（仅模糊无叠色）
    }
}

fun CMSGlassTopBarPadding(topInset: Dp): Dp = topInset
```

### 1.6 用法

```kotlin
val hazeState = rememberHazeState()
CMSGlassPage(
    topInset = statusBarHeight,
    hazeState = hazeState
) { hs ->
    CMSecondaryGlassTopBar(
        title = "设置",
        topInset = statusBarHeight,
        hazeState = hs,
        onBack = { finish() }
    )
}   // ← 注意：topBar / content 两个尾随 lambda
```

**依赖**：`haze`（含 `hazeSource`/`hazeEffect`/`blurEffect`）、`liquidglass`、
`continuous-rounded-corner`、`R.drawable.chevron_left`、主题。

## 2. CMSBottomBar — 悬浮玻璃底栏

`cms/CMBottomBar.kt` · `class CMSBottomBar(context) : LinearLayout`

**作用**：应用的底部悬浮栏，液态玻璃材质，支持 Tab 导航与迷你播放器横向并排。

**模式**

```kotlin
enum class Mode { TABS_ONLY, MINIPLAYER_ONLY, COMBINED }
```

**初始化**

```kotlin
val bottomBar = CMSBottomBar(context)
bottomBar.build(
    contentContainer = glassSampleContainer,       // LiquidGlass 采样容器（可为 null 降级）
    mode = CMSBottomBar.Mode.COMBINED,
    onMiniTapCollapse = { /* 点击迷你播放器收起 */ },
    tabContent = { brightness -> TabRow(brightness) },
    miniPlayerContent = { brightness -> MiniPlayer(brightness) }
)
root.addView(bottomBar)
```

`tabContent` / `miniPlayerContent` 的入参 `brightness`（0..1）用于按玻璃下方亮度自适应内容明暗。

**外部弹簧驱动**（展开 / 收起迷你播放器）

```kotlin
val driver = SpringDriver(stiffness = 320f, damping = 30f)
driver.onUpdate = { p -> bottomBar.applySpringProgress(p, screenWidthPx) }
driver.setTarget(if (expanded) 1f else 0f)
```

**公开成员**：`tabGlassRef`、`miniGlassRef`、`tabGlassOriginalWidthPx`、
`tabContentBrightness`、`miniContentBrightness`、`applySpringProgress()`、`updateAdaptiveTint()`。

**依赖**：`liquidglass`、`continuous-rounded-corner`。

## 3. CMSProgressBar / CMSProgressDot — 进度条

`cms/CMProgressBar.kt`

```kotlin
@Composable
fun CMSProgressBar(
    progress: Float,
    onSeekBegin: () -> Unit = {},
    onSeek: (Float) -> Unit = {},
    onSeekEnd: () -> Unit = {},
    modifier: Modifier = Modifier,
    selectedColor: Color = Accent,
    dotStyle: CMSProgressDot = CMSProgressDot.None,
    range: ClosedFloatingPointRange<Float> = 0f..1f,
    steps: Int = 0,                  // >0 时按档位吸附
    readOnly: Boolean = false,
    enabled: Boolean = true,
    dotRingColor: Color? = null,
    dotFillDark: Color? = null,
    dotFillLight: Color? = null,
    dotStretch: Dp = 6.dp,
    vertical: Boolean = false,
    liveUpdate: Boolean = false
)

enum class CMSProgressDot { None, Hollow, Solid }
```

**要点**
- `steps > 0`：拖动松手按档位吸附（`CMSSwitch` 复用了该语义）。
- 越界拖动 / 快速滑动会触发行进中的形变与回弹（越界量只参与绘制，不回传业务层）。
- `liveUpdate = true`：外部高频刷新进度（如逐帧播放进度）时的低开销路径。

**依赖**：主题。

## 7. CMSelectMenu — 毛玻璃浮层菜单

`cms/CMSelectMenu.kt`

```kotlin
@Composable
fun CMSelectMenu(
    hazeState: HazeState,
    items: List<CMSelectMenuItem>,
    currentIndex: Int,
    anchorRect: IntRect,
    visible: Boolean,
    onSelect: (Int) -> Unit,
    onDismiss: () -> Unit,
    type: CMSMenuType = CMSMenuType.Select
)

data class CMSelectMenuItem(
    val label: String,
    val icon: ImageVector? = null,
    val shortcut: String? = null,
    val danger: Boolean = false,
    val disabled: Boolean = false,
    val badge: String? = null,
    val subArrow: Boolean = false,
    val subItems: List<CMSelectMenuItem>? = null
)

enum class CMSMenuType { Select, Actions, SortFilter }
```

**要点**
- 由外部提供触发锚点 `anchorRect` 与显示请求 `visible`。
- 带 `subItems` 的行会锚定该行弹出二级菜单。
- 超过 4 行自动进入滚动布局（配合 `CMScrollBox` 侧边滚动条）。
- 进出场为 C++ spring + 高斯模糊。
- 平板上（`screenWidthDp >= TABLET_MIN_DP`）按锚点位置决定向左 / 向右展开。

**依赖**：`haze`、`continuous-rounded-corner`、`CLEARMotion`、`TabletLayout`（`TABLET_MIN_DP`）、主题。

## 9. CMSPlayerBackground — 播放器流体背景（可选）

`cms/optional/CMPlayerBackground.kt` —— **业务组件，不能单独编译**

```kotlin
@Composable
fun CMSPlayerBackground(
    coverUrl: String,
    isPlaying: Boolean,
    energy: Float,
    modifier: Modifier = Modifier
)
```

封面取色 + 多瓣流体形变 + 能量驱动呼吸；依赖 Coil 加载封面。

> ⚠ 该组件在源工程内直接读写：
> - `PlayerViewModel.isExpanded` / `PlayerViewModel.bgBaseColor`
> - `PerformanceGovernor.getThrottle(RenderSubsystem.FLUID)`
>
> 而 `PlayerViewModel` 又引用 `AudioPlayer`（播放引擎）。因此它**不属于**通用组件集，
> 已单独放在 `cms/optional/`。引入前需把上述状态与调度替换为本地实现。

**依赖**：`coil-compose`、`TabletLayout`（`screenScaleFactor()`）、应用侧 `PlayerViewModel` / `PerformanceGovernor`。

## 13. CMHalfModal — 半模态

`cms/halfmodal/CMHalfModal.kt`，将 `cms/halfmodal` 加入应用的 main 源目录即可使用。

```kotlin
CMHalfModal(onDismiss = { visible = false }, heightFraction = 0.86f, maxHeight = 640.dp) {
    // ColumnScope 正文；内部 verticalScroll 可在触顶后继续下拉面板。
}
```

手势条宽 48dp。入场、回弹和退场共用位移弹簧，支持拖拽打断、松手动量、遮罩关闭和系统返回；退场完成后才调用 `onDismiss`。默认不提供关闭按钮。
