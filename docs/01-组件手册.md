# 01 · 组件手册（v1.1.0）

每个组件的独立文档位于 [`components`](components/)，包含调用入口、参数、状态归属、交互规则、接入边界和通用代码示例。

中英文组件名与旧接口迁移见 [`05-组件命名.md`](05-组件命名.md)。旧接口继续兼容。

页面内模式切换使用 [胶囊导航](components/CapsuleNavigation.md) `CMS.Navigation.CapsuleNavigation`；
固定少量分类也可使用 [标签导航](components/TabNavigation.md) `CMS.Navigation.TabNavigation`。
旧分段接口继续兼容。
支持 2～4 个选项，高度 44dp、内缩 4dp，外框与选中指示器圆角分别为 22dp / 18dp，
文字 14sp，选中指示器以可打断的弹簧滑动。默认使用中性底板，
`variant = CMSCapsuleVariant.Outlined` 切换为描边版（旧分段接口使用 `outlined = true`）。

[触控优先级](components/TouchPriority.md)、[玻璃融合](components/GlassFusion.md) 和 [返回历史](components/BackHistory.md) 提供接口说明与完整接入代码。
[交互教程索引](components/InteractionGuide.md) 列出接入顺序和组合使用规则。
`CMS.Interaction.TouchPriority` 统一配置方向竞争，完整页面推荐 `CMS.Content.Pager + Page` 自动连接每页主滚动；
已有复杂原生 Pager 可用 `Modifier.cmsPagerTouchPriority` 适配。默认 `respectConsumedGestures = false`，抬手再按下会重新判向；
表格、代码与宽内容用 `CMS.Content.HorizontalScrollView` 或 `Modifier.cmsHorizontalScrollTouchPriority`，自动避让父级切页并连续交接纵滑；上下左右抖动与按住快速换向也属于触控优先级。
`CMS.Interaction.GlassFusion` 为同一组玻璃分配独立组号，`GlassSearch` 提供搜索 / 取消分离回收。
`CMS.Interaction.BackHistory` 为返回按钮提供真实页面历史和长按跨级返回，嵌套主题默认继承历史。

## 1. 主题与宿主接口

### 1.1 主题与外观 · Theme & Appearance · `CMSTheme`

一次性提供色板、玻璃材质、内容采样状态、震动与返回历史。

```kotlin
@Composable
fun CMSTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    glassMaterial: GlassMaterial = GlassMaterial(),
    hazState: HazeState = remember { HazeState() },
    hapticsEnabled: Boolean = true,
    haptics: CMSHapticsProvider? = LocalCMSHaptics.current,
    backHistory: CMSBackHistory? = LocalCMSBackHistory.current,
    accentColor: Color? = null,
    content: @Composable () -> Unit
)
```

宿主已有自己的主题时，也可以不调用 `CMSTheme`，只在 `CompositionLocalProvider` 中提供下表 Local：

| Local | 类型 | 默认 | 作用 |
| --- | --- | --- | --- |
| `LocalClearIsDark` | `Boolean` | `true` | 玻璃高光/色调的明暗判断 |
| `LocalGlassMaterial` | `GlassMaterial` | `GlassMaterial()` | 高级材质与通透度档位 |
| `LocalGlassHazeState` | `HazeState?` | `null` | 毛玻璃控件的采样源 |
| `LocalCMSHaptics` | `CMSHapticsProvider?` | `null` | 局部震动实现覆盖 |
| `LocalCMSHapticsEnabled` | `Boolean` | `true` | 局部震动开关 |
| `LocalCMSBackHistory` | `CMSBackHistory?` | `null` | 返回按钮长按历史 |
| `LocalCMSAccentColor` | `Color` | 默认蓝色 | 当前主题局部强调色 |

### 1.2 `GlassMaterial`

```kotlin
data class GlassMaterial(val advanced: Boolean = true, val clarity: Int = 1)
// clarity: 0 毛玻璃 / 1 舒适 / 2 通透
// frosted    = advanced && clarity == 0
// optical    = advanced && clarity != 0
// blurRadius = 8f (clarity 2) / 25f
```

### 1.3 色板

`library/theme/Color.kt` 提供可观察 token：`PageBackground`、`CardBackground`、`SecondaryCard`、`TertiaryFill`、`ImagePlaceholder`、`DividerColor`、`AccentBlue`、`LinkBlue`、`PrimaryText`、`SecondaryText`、`TertiaryText`。

切换主题时调用 `applyDarkPalette()` / `applyLightPalette()`，所有读取处自动重组。1.0 的 `Accent`、`Divider`、`SecondaryCardBackground`、`Light*` 保留为兼容别名。

## 2. 玻璃组件

### 设置列表 · Settings List

`library/cms/CMSSettings.kt` 提供统一的设置页布局参数，卡片内不自动添加间距。
用 `CMSSettingsDivider()` 显式分隔行；卡片连续圆角 20dp、内边距 18dp，
标题 15sp、说明 11sp。`CMSSettingsMenuRow` 使用高度 25dp 的实色胶囊，
通过 `cmsMenuAnchor` 继承长按滑动会话；`onOpen` 返回窗口坐标，可直接传给 `CMSPopupMenu`。

```kotlin
CMSSettingsSectionTitle("通用")
CMSSettingsCard {
    CMSSettingsSwitchRow("高级材质", "折射、高光与背景模糊",
        checked = advanced, onCheckedChange = { advanced = it })
    CMSSettingsDivider()
    CMSSettingsMenuRow("通透度", value = clarityName,
        enabled = advanced, onOpen = { anchor = it; menuVisible = true })
    CMSSettingsDivider()
    CMSSettingsNavRow("外观", "跟随系统、浅色或深色界面",
        onClick = onOpenAppearance)
}
```

`CMSSecondaryTopBar` 为整条 51dp 覆盖：左右 12dp、返回按钮 44dp、标题 18sp 居中、
底部全宽 1dp 分隔线，底色始终实色绘制，模糊层只叠加质感。它不含状态栏区域，
调用方用 `windowInsetsPadding(WindowInsets.safeDrawing)` 包住整列，状态栏区域保持页面底色。

```kotlin
Column(Modifier.fillMaxSize().windowInsetsPadding(WindowInsets.safeDrawing)) {
    CMSSecondaryTopBar(title = "设置", hazeState = haze, onBack = { finish() })
    CMSScrollView(Modifier.fillMaxWidth().weight(1f).hazeSource(haze)) {
        // padding(start = 16.dp, end = 16.dp, top = 12.dp, bottom = 16.dp)
    }
}
```

默认静态模糊 20dp、页面色染色 68%、失焦底色 94%，不使用渐进模糊。
旧版 `CMSecondaryGlassTopBar` 保留 `topInset` 参数，继续按状态栏占位 + 顶栏避让的方式工作。
`CMSTheme` 统一处理浅色字号补偿 2%，调用方文字无需再次乘倍率。

### 2.1 玻璃按钮 · Glass Button · `CMSGlassButton`

通用液态玻璃按钮：文字胶囊、图标按钮、菜单表面、可编辑玻璃面板都由它渲染。

```kotlin
@Composable
fun CMSGlassButton(
    onClick: () -> Unit,
    modifier: Modifier = Modifier,
    width: Dp = 36.dp,
    height: Dp = 36.dp,
    enabled: Boolean = true,
    useNativeGlass: Boolean = true,
    sampleContent: Boolean = false,
    samplingSource: ViewGroup? = null,
    hazeState: HazeState? = null,
    menuSurface: Boolean = false,
    shadowStrength: Float = if (menuSurface) 3f else 1f,
    exclusiveTouchGesture: Boolean = false,
    interactiveContent: Boolean = false,
    touchEffectIntensity: Float = 1f,
    glassTint: Color = Color.White,
    glassTintAlpha: Float? = null,
    glassBackground: Color = Color.White.copy(alpha = 0.08f),
    motionBlur: Dp = 0.dp,
    metaballGroupId: String? = null,
    metaballProximityOnly: Boolean = false,
    metaballAnchorRight: Boolean = false,
    metaballMergeGap: Dp = 18.dp,
    metaballProgress: Float = 1f,
    metaballColor: Color = Color.White,
    gravityStrength: Float = 1f,
    metaballEmergence: Float = 1f,
    cornerRadius: Dp? = null,
    touchEffectRadius: Dp = 100.dp,
    highlightMaxWidth: Dp = Dp.Infinity,
    highlightWidthScale: Float = 1f,
    externalTouchFeedback: Boolean = false,
    feedbackPosition: Offset? = null,
    onLongClick: (() -> Unit)? = null,
    onTouch: ((Offset, Int) -> Boolean)? = null,
    content: @Composable (Color) -> Unit
)
```

**布局与外观**

| 参数 | 说明 |
| --- | --- |
| `width` / `height` | 控件尺寸；内容不会改变布局尺寸 |
| `cornerRadius` | 圆角，默认 `height / 2`（胶囊） |
| `glassTint` / `glassTintAlpha` | 玻璃染色与透明度；`null` 时按明暗取 0.05/0.06 |
| `glassBackground` | 内容底色（叠加在玻璃表面） |
| `highlightMaxWidth` | 高光/描边最大宽度，单位 dp；默认自动调整且不超过 0.8dp，0 隐藏；融合与降级描边也遵循此上限 |
| `highlightWidthScale` | 在自动宽度上收细，默认 1；亮背景与按压只增强光照，原生放大形变补偿宽度 |
| `shadowStrength` | 投影强度，菜单表面默认 3 |
| `motionBlur` | 形变时的动态模糊半径 |

**采样（关键）**

| 参数 | 说明 |
| --- | --- |
| `sampleContent` | `true` 时采样页面内容；`false` 只采样纯色背景（默认） |
| `samplingSource` | 显式指定采样 `ViewGroup`，优先级最高 |
| `adaptiveAppearance` | 默认 `false`；开启后原生玻璃色调及内容前景色随采样亮度平滑变化 |
| `hazeState` | 毛玻璃降级模式的 Haze 采样状态 |

> 采样源**绝不能包含按钮自身**，否则 HWUI 会形成 RenderNode 循环引用并闪退。内核在 `LiquidGlassView.bind()` 中已做祖先检测，被拒绝时控件退化为纯色采样。

**融合（metaball）**

`metaballGroupId` 相同的按钮在同一窗口内融合为一个光学表面：`metaballAnchorRight` 标记主/从，`metaballMergeGap` 控制合并距离，`metaballProximityOnly` 仅在靠近时融合，`metaballProgress` / `metaballEmergence` 驱动分离动画，`metaballColor` 指定染液颜色。

**交互**

| 参数 | 说明 |
| --- | --- |
| `onLongClick` | 长按（阈值 `CM_MENU_HOLD_MILLIS`，默认 180ms） |
| `onTouch` | 触摸观察器，返回 `true` 表示该次触摸由外部接管（菜单手势） |
| `exclusiveTouchGesture` | 原生玻璃在按下请求独占；默认保留玻璃拖动，glassDragPriority = false 时 CMS Pager / ScrollView 可接管，普通列表按钮默认关闭 |
| `interactiveContent` | 允许内部 Compose 内容接收输入（可编辑面板） |
| `externalTouchFeedback` / `feedbackPosition` | 由外部（如菜单）驱动触点高光 |
| `touchEffectIntensity` / `touchEffectRadius` | 触点高光强度与半径 |

**示例**

```kotlin
CMSGlassButton(
    onClick = { /* ... */ },
    width = 36.dp,
    height = 36.dp,
    sampleContent = true
) { color ->
    Icon(painterResource(R.drawable.ic_gear), null, tint = color, modifier = Modifier.size(20.dp))
}
```

### 2.2 返回按钮 · Back Button · `CMSBackButton`

```kotlin
@Composable
fun CMSBackButton(
    onClick: () -> Unit,
    modifier: Modifier = Modifier,
    iconColor: Color? = null,
    exclusiveTouchGesture: Boolean = false
)
```

- 短按：执行 `onClick`；
- 长按：从 `LocalCMSBackHistory` 取历史页面并弹出选择菜单；
- 菜单运行在独立 `Popup` 窗口，天然位于原生/Haze 采样树之外，不会自采样；
- 宿主未提供 `CMSBackHistory` 时，长按无动作，短按照常。
- 列表内专门展示玻璃形变时可传 `exclusiveTouchGesture = true`；导航顶栏保持默认。

### 2.3 玻璃采样源 · Glass Content Source · `CMSGlassContentSource`

页面内容采样宿主：把“内容”与“顶栏/浮层”分成兄弟节点，玻璃只采样内容。

```kotlin
@Composable
fun CMSGlassContentSource(
    modifier: Modifier = Modifier,
    sourceTag: String = CMS_GLASS_CONTENT_SOURCE_TAG,
    onSourceReady: (ViewGroup) -> Unit = {},
    hazeState: HazeState? = null,
    content: @Composable () -> Unit
)
```

- 生成一个带 `CMS_GLASS_CONTENT_SOURCE_TAG` 的 `FrameLayout`，内部包 `ComposeView`；
- `hazeState != null` 或材质为毛玻璃时，自动挂 `hazeSource`；
- 顶栏、悬浮按钮、菜单必须放在它**外面**，否则会被算进采样源，形成自采样或重复采样。

### 2.4 滑块 · Slider · `CMSSlider`

滑块按方向判定拖动：横向滑块上的纵向滑动交由列表处理。
点击、拖动、越界松手与回弹中再次拖动共用连续的物理状态，不重置当前位置或速度。
`range` 与 `steps` 支持数值区间及档位吸附，业务回调始终限制在区间内。

```kotlin
CMSSlider(
    value = value,
    onValueChange = { value = it },
    thicknessAnimation = true,
    dampingEnabled = true,
    overscrollEnabled = true
)
```

- `thicknessAnimation`：按压增粗、松手回细及越界渐细；关闭后轨道保持 6dp。
- `dampingEnabled`：轻微延迟跟随；关闭后数值直接跟手，端点回位仍由弹簧完成。
- `overscrollEnabled`：端点外拉伸与回弹；关闭后拖动值限制在端点。
- 横向触控容器高度 32dp，轨道在内部居中，粗细变化不改变布局高度。

## 3. 菜单与滚动

### 3.1 弹出菜单 · Popup Menu · `CMSPopupMenu`

```kotlin
@Composable
fun CMSPopupMenu(
    hazeState: HazeState,
    items: List<CMSMenuItem>,
    currentIndex: Int,
    anchorRect: IntRect,
    visible: Boolean,
    onSelect: (Int) -> Unit,
    onDismiss: () -> Unit,
    type: CMSMenuType = CMSMenuType.Select,
    accentColor: Color = Color(0xFFFF5B68),
    onSelectPath: ((List<Int>) -> Unit)? = null,
    dimBackground: Boolean = false,
    dimAmount: Float = 0.24f,
    touchState: CMSMenuTouchState? = null,
    onClosed: (() -> Unit)? = null,
    samplingSource: ViewGroup? = null
)
```

1.1.0 行为：

- **屏下 1/3 向上弹**：触发点落在窗口下 1/3 时，即使下方仍有空间也优先向上展开，并在顶部保留安全边距；二级菜单同样按该规则定位；
- **一次触摸完成选择**：`touchState` 让锚点把同一次按住的触摸交给菜单，滚动与悬停选择不松手；
- **退场保留内容**：`visible = false` 后仍按最后一次 `items` / `currentIndex` 渲染，避免内容先消失；
- **二级菜单**：`CMSMenuItem.subItems` 非空时在对应行旁展开，`onSelectPath` 返回完整路径；
- **菜单项动作**：`CMSMenuItem.onClick` 在选中时执行。
- **跨窗口采样**：`samplingSource` 可固定原页面内容源，返回历史菜单已自动传递；
  原生渲染以屏幕坐标对齐，并在菜单窗口绘制时刷新采样位置。

`CMSMenuItem` 字段：`label`、`icon`、`shortcut`、`danger`、`disabled`、`badge`、`subArrow`、`subItems`、`onClick`。

### 3.2 滚动视图 · Scroll View · `CMSScrollView`

```kotlin
@Composable
fun CMSScrollView(
    modifier: Modifier = Modifier,
    scrollState: ScrollState = rememberScrollState(),
    scrollEnabled: Boolean = true,
    showScrollbar: Boolean = false,
    springOverscroll: Boolean = false,
    lazyGridState: LazyGridState? = null,
    onOverscrollChanged: (Float) -> Unit = {},
    axisDragBridge: CMSVerticalDragBridge? = null,
    onUserScroll: (Float) -> Unit = {},
    onScrollRelease: (Float) -> Unit = {},
    onScrollPress: () -> Boolean = { false },
    sampleGlassContent: Boolean = true,
    scrollbarStyle: CMSScrollbarStyle = CMSScrollbarStyle.Classic,
    scrollbarInteractive: Boolean = true,
    scrollbarPressThickening: Boolean = true,
    scrollbarSections: List<CMSScrollSection> = emptyList(),
    scrollbarInsets: PaddingValues = PaddingValues(8.dp),
    scrollbarIndexLayout: CMSScrollbarIndexLayout = CMSScrollbarIndexLayout.TopPacked,
    content: @Composable ColumnScope.() -> Unit
)
```

- `sampleGlassContent = true`（默认）时，内部自动套一层 `CMSGlassContentSource`，把滚动区域作为玻璃采样源；页面顶栏不要放进这个 `CMSScrollView`；
- 如果需要自己控制采样边界，设为 `false` 并手动放置 `CMSGlassContentSource`；
- `lazyGridState` 用于 Lazy 网格：保留 CMS 的越界/惯性/滚动条物理；
- `axisDragBridge` 允许菜单等子层接管纵向拖拽（见 `CMSVerticalDragBridge`）；
- `onOverscrollChanged` 正值表示顶部越界，可用于下拉唤起搜索等。
- `springOverscroll = false` 禁止拖动与惯性越界，保留正常惯性滚动；运行中关闭会清除已有越界。
- 滚动条默认支持拖动定位，按下从 4dp 加粗至 8dp，松手弹簧恢复；可分别关闭 `scrollbarInteractive` 和 `scrollbarPressThickening`。经典轨道宽 10dp，索引轨道宽 16dp，字母默认 10sp，高亮最高 18dp；分段小标题随条宽连续让位。启用索引样式时内容右侧额外预留 12dp；按下后触摸可连续拖出轨道。
- `scrollbarIndexLayout` 控制首字母排列：`TopPacked`（默认）在轨道顶部按 22dp 间距聚集，`Distributed` 均匀分散到整条轨道；布局与触摸映射共用同一范围，聚集区外不拦截首次触摸。分段索引保持分散排列。
- 开启 `springOverscroll` 时，实际触底后继续拖动会使内容越界，滚动条锚定边缘缩短，松手沿用列表的速度与回弹参数；末组不足一屏时同样按实际底部处理，普通滚动到底也选中末组。关闭时内容与滚动条始终保持在边界内。
- `scrollbarStyle` 支持 `Classic`（经典）、`Alphabet`（首字母索引）、`Sections`（分段索引）。后两种通过 `scrollbarSections` 绑定实际分组，选择高亮连续弹簧移动；按住时弹出高度 36dp 的液态玻璃圆胶囊，位置阻尼跟随。光学玻璃下，速度驱动独立的拉伸和弯曲弹簧，API 33+ 通过非线性变形同步处理轮廓、折射、高光、内容及阴影，停止和反向后保留回弹；文字切换叠加模糊，进退场采用弹簧与整体模糊；没有分组数据时使用经典样式。
- 提示胶囊吸附当前索引中心，只保留 10% 的组内手指位移影响；跨组弹簧移动，边缘拉伸仍与内容越界联动。使用启用硬件加速的独立窗口与额外模糊绘制空间，原生玻璃与形变着色器可正确绘制采样内容；采样不包含胶囊自身，退场完成后才销毁窗口。
- `CMSScrollSection(label, scrollOffset = 0, itemIndex = 0)`：普通滚动填写内容顶部起算的像素偏移；Lazy 网格填写项目下标。分组需按内容顺序提供，标题位置应随布局重新测量。
- Lazy 网格经典滚动条依据可见行高度估算长内容尺寸，混合行高时指示比例可能变化；分组索引按项目下标精确定位。
- `scrollbarInsets` 只调整滚动条轨道，可为顶栏和导航栏预留空间，不改变内容布局。

### 3.5 轮播视图 · Carousel · `CMSCarousel`

轮播的页面与指示共同读取实际位移，拖动、惯性滑动、吸附及边缘回弹期间连续同步。圆点按实际长度排布，相邻边缘始终相隔 5dp；纵向轮播在右侧竖排指示。数字指示按分页进度交叠切换。动效使用实际帧时间，松手速度传入弹簧，重新按下可中断；静止时不运行物理帧循环。嵌入 `CMSScrollView` 时自动接入其滚动物理接口，横向翻页与纵向滚动支持不抬手换向；纵向轮播区域内的纵向拖动用于翻页，区域外用于页面滚动。

| 参数 | 默认值 / 行为 |
| --- | --- |
| `direction` | `Horizontal`；也支持 `Vertical`，横向手势不抢占纵向列表滚动 |
| `autoPlay` / `autoPlayInterval` | `false` / `3000L`；拖动与动画期间暂停，自由滑动模式不自动翻页 |
| `showArrows` | `false`；点按前后切换，边缘禁用；独立采样轮播页面，玻璃色调与箭头颜色随背景亮度自适应 |
| `arrowSize` | `28.dp`；玻璃按钮直径，图标按直径一半缩放；复用返回箭头，下一页镜像，纵向旋转 |
| `edgeOverflow` | `Spring`；`None` 禁止拖动和惯性越界 |
| `snapBack` | `true`；关闭后松手惯性停在任意位置 |
| `freeMode` / `pageWidthFraction` | `false` / `1f`；自由模式可设置页面占比，末端按实际内容宽度或高度停靠 |
| `pageHeight` / `pageSpacing` / `clipRadius` | `140.dp` / `8.dp` / `12.dp` |
| `indicatorStyle` | `DotIndicator`；支持 `None`、`DigitIndicator`，自由模式也可显示 |
| `indicatorVisibleCount` | `5`；圆点窗口可见数量，不超过总页数 |
| `indicatorSize` / `indicatorActiveWidth` | `6.dp` / `14.dp` |
| `indicatorBottomInset` | `8.dp`；横向为底部距离，纵向为右侧距离 |
| `indicatorInteractive` / `indicatorColor` | `true` / `AccentBlue`；圆点支持点按定位 |

## 5. 采样与层级规则

正确的页面结构：

```text
Box
├── CMSGlassContentSource       // 只包页面内容（可滚动区域）
│   └── 内容
├── 顶栏（含 CMSBackButton）     // 玻璃控件，与内容采样源平级
├── 悬浮玻璃按钮                 // 同上
└── CMSPopupMenu                // 菜单浮层，最上层
```

三条硬规则：

1. 玻璃控件不能位于自己的采样源内部；
2. 同一页面只保留一个页面级采样源（`CMS_GLASS_CONTENT_SOURCE_TAG`）；
3. 长按菜单优先放在独立 `Popup`（参考 `CMSBackButton`），彻底隔离采样树。

违反第 1 条时，`LiquidGlassView.bind()` 会拒绝绑定（防 HWUI 递归闪退），表现为“玻璃只剩纯色/高光”。

## 6. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 玻璃只显示纯色，没有折射 | 采样源被祖先检测拒绝，或 `sampleContent = false` | 调整 `CMSGlassContentSource` 边界，或开启 `sampleContent` |
| 长按菜单闪退 | 菜单被放进采样源，形成 RenderNode 循环 | 用独立 `Popup`，或把菜单移出采样源 |
| 屏幕下方弹出菜单不好点 | 1.0 行为：仅在下方放不下时向上 | 1.1.0 已默认屏下 1/3 向上弹 |
| 顶栏内容被算进模糊 | 顶栏放在了 `CMSScrollView` / 采样源内部 | 把顶栏移到采样源外，作为兄弟节点 |
