# 05 · 组件命名

界面采用简洁中文名称和标准英文名称；公开组件函数统一使用 CMS 前缀。材质、动效与实现方式通过参数表达。

| 中文名称 | English | 推荐接口 | 兼容旧接口 |
| --- | --- | --- | --- |

| 返回按钮 | Back Button | CMS.Navigation.BackButton | CMSBackButton / CMSGlassBackButton |
| 玻璃采样源 | Glass Content Source | CMS.Content.Source | CMSGlassContentSource / CMGlassContentSource |
| 设置列表 | Settings List | CMS.Content.List / Section / ListRow / ToggleRow / MenuRow | CMSSettingsCard / CMSSettings*Row |
| 切换开关 | Switch | CMS.Controls.Toggle | CMSSwitch |
| 滑块 | Slider | CMS.Controls.Slider | CMSSlider / CMSProgressBar |
| 弹出菜单 | Popup Menu | CMS.Controls.Menu | CMSPopupMenu / CMSelectMenu |
| 滚动视图 | Scroll View | CMS.Content.ScrollView | CMSScrollView / CMScrollBox |

设置列表是一组布局组件，保持 Card、SectionTitle、Divider、NavRow、SwitchRow、MenuRow 各自的职责。
分段控件用于互斥的控件值；页面内分类使用胶囊导航。
Tab 栏、胶囊导航、标签导航统一属于 Tabbar 家族：玻璃、胶囊、下划线是三种外观形态，分别保留 `TabView`、`CapsuleNavigation`、`TabNavigation` 调用入口，均由宿主持有选中状态。调用关系见 [Tabbar](components/TabBar.md)。
返回按钮属于导航组件；长按查看页面历史、滑动选择与跨级返回作为“返回历史”独立归入交互。

## 参数迁移

| 组件 | 旧参数 | 新参数 |
| --- | --- | --- |
| 滑块 | progress / onSeek | value / onValueChange |
| 滑块 | onSeekBegin / onSeekEnd | onValueChangeStarted / onValueChangeFinished |
| 滑块 | dotStyle | thumbStyle |
| 滑块 | dotRingColor / dotFillDark / dotFillLight / dotStretch | thumbRingColor / thumbFillDark / thumbFillLight / thumbStretch |
| 轮播视图 | navBar | indicatorStyle |

滑块的 readOnly 支持只读数值展示，range 与回调均使用实际数值区间。

## 类型与手势接口

| 推荐名称 | 原名称 |
| --- | --- |
| CMSSliderThumbStyle | CMSProgressDot |
| CMSMenuItem | CMSelectMenuItem |
| CMSMenuTouchState / rememberCMSMenuTouchState | CMMenuTouchState / rememberCMMenuTouchState |
| Modifier.cmsMenuAnchor | Modifier.cmMenuAnchor |
| CMSScrollbarStyle / CMSScrollbarIndexLayout | CMScrollbarStyle / CMScrollbarIndexLayout |
| CMSScrollSection / CMSVerticalDragBridge | CMScrollSection / CMVerticalDragBridge |
| CMSCarouselDirection | CMSwipeDirection |
| CMSCarouselOverscroll | CMSEdgeOverflow |
| CMSCarouselIndicator | CMSNavBar |
| CMSTabPlacement / CMSTabForm | —（新增） |
| CMSSettings / LocalCMSSettings / CMSDefaults | —（新增） |

新入口位于 cms/CMSComponents.kt 与 cms/CMS.kt：`CMS` 门面是唯一推荐调用入口，参数委托给现有实现；
`CMSSettings` + `CMSDefaults` 提供全局默认值，组件参数为 `null` 时回落到全局。旧顶层函数保留完整参数和默认值，
其中部分旧入口标记 Deprecated；类型别名共用原有枚举、数据与触摸状态，旧调用与新调用可以共存。
Tab 栏的位置与形态见 [06-统一入口与全局配置.md](06-统一入口与全局配置.md)。

独立文档与公开接口说明使用本表名称；兼容名称通过旧入口和类型别名继续提供。
